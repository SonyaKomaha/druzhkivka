# Druzhkivka Regular

A display all-caps sans-serif typeface with Latin and Cyrillic support,
inspired by Druzhkivka, my hometown in eastern Ukraine.

## About

This typeface is a tribute to a place that can no longer be returned to.
It is made for posters, signage, banners, social media graphics, logos and
apparel design. The design began with the Cyrillic capital Д, recreated from
memory. The punctuation is deliberately thin, in contrast with the bold
letterforms.

## Character set

177 unique glyphs, Latin and Cyrillic. The font is all-caps: lowercase
characters produce the same capital forms.

Supported languages: Ukrainian, Belarusian, Bulgarian, Rusyn, Polish, English,
German, French, Spanish, Portuguese, Italian, Catalan, Galician, Occitan,
Basque, Dutch, Danish, Norwegian, Swedish, Finnish, Icelandic, Faroese,
Estonian, Albanian, Luxembourgish, Irish, Scottish Gaelic, Indonesian / Malay,
Swahili, Zulu / Xhosa, Somali, Filipino, Latin.
